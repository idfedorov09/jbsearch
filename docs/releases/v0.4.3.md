# JB Search v0.4.3

This stable release brings the 0.4.0 and 0.4.2 pre-release changes to users of
the stable channel. The extension ID remains `idfedorov09.jbsearch`; the bundled
client remains at version 0.1.0.

## Stable search results

- Completed Find Panel results form a deterministically ordered snapshot across
  supported source changes. Changed results are revalidated, and **Rerun Search**
  rebuilds the snapshot to discover new matches.
- Occurrences are tracked across supported edits. Stale, ambiguous, pending, and
  unverified replacement targets are refused instead of silently selecting a
  different occurrence. Native TreeView delivery and exact scroll preservation
  remain subject to the documented limitations.
- Intermediate result updates are coalesced, and repeated processing of
  replacement plans is reduced without removing the existing safety checks.

These changes are intended to address the unexpected refresh and reordering
reported in [issue #3](https://github.com/idfedorov09/jbsearch/issues/3). The
original Windows/WSL scenario has not yet been verified; the issue remains open
for reporter feedback.

## Replacement and diagnostics

- Replace All compares a fresh, complete search of the full scope with the
  reviewed replacement plan and refuses an incomplete or different plan.
- The new `jbsearch.replace.prepareTimeoutMs` setting controls replacement
  preparation. A stale search can be rerun from the modal, and Replace All is
  available from a match's context menu.
- The modal keeps aggregate warnings for skipped files. **Open in Find Panel**
  retains bounded representative paths and reasons. Binary detection remains
  heuristic, so review exclusions before bulk replacement.

## Verification and limitations

Automated regression checks cover result snapshots, occurrence identity,
replacement preflight, diagnostics, and packaging. They do not establish real
VS Code or platform acceptance. Native VS Code, Windows/WSL, macOS, and physical
Remote acceptance of these changes remain unverified.

Desktop VS Code **1.143.1+** and a filesystem workspace are required. See the
[README](https://github.com/idfedorov09/jbsearch/blob/v0.4.3/README.md) for
usage, privacy, and implementation limits.
