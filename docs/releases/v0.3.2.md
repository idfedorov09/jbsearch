# JB Search v0.3.2

## Fixes

- Inputs identified as binary, including ZIP/DOCX containers and common image
  and document formats, are excluded from text search without making results
  incomplete solely because they are present. Replace All can operate on the
  eligible text matches and does not change the excluded files.
- Search diagnostics list representative excluded or skipped paths and reasons.
  Detected unsupported encodings, inaccessible files, unknown oversized inputs,
  timeouts, result limits, and stale or unverified results retain their existing
  replacement safeguards.

Binary detection is heuristic, not a guarantee: binary data that resembles text
may still be searched, and text can be mistaken for binary. Review the reported
exclusions before applying a bulk replacement. The bundled client remains at
version 0.1.0.

Since the previous GitHub release (v0.3.0), this release also includes the
manually dispatched Open VSX publishing workflow introduced in version 0.3.1.

## Verification and limitations

Automated tests cover the search worker, diagnostics, and replacement guards.
An automated VS Code 1.144.1 Extension Development Host check on Linux/X11
verified binary exclusions, actual unsaved workspace edits, Undo, and a detected
unsupported encoding. It was not a hands-on manual acceptance test. The change
has not been verified on macOS, Windows, or a physical Remote SSH connection.

Desktop VS Code **1.143.1+** and a filesystem workspace are required. See the
[README](https://github.com/idfedorov09/jbsearch/blob/v0.3.2/README.md) for usage
and classification limits.
