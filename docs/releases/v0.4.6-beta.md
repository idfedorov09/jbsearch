# JB Search 0.4.6 pre-release preparation

This document describes a candidate prepared on `dev`; it is not evidence of
publication. An authorized, reviewed `dev` to `beta` pull request and the
protected publication environments remain separate release steps.

## Changes since pre-release 0.4.5

- Continue to preflight all packages and verify the universal fallback before
  uploading any platform-specific target. Upload the six targets sequentially,
  but overlap their exact registry checks, with bounded request concurrency.
- Require exact identity, version, platform, channel and SHA-256 verification
  for all seven artifacts. Stop starting further uploads after a known failure,
  drain started checks, and report confirmed, uncertain and unattempted targets.
- Do not rely on duplicate skipping or an ambiguous upload failure. Confirm an
  exact existing record before continuing. Marketplace uses the pinned public
  `vsce` API with an explicit acknowledgement rather than treating a zero CLI
  exit as proof of acceptance; this avoids a cancellation ambiguity.
- Report process completion and verification durations separately and classify
  retry causes without exposing raw registry errors or credentials. The existing
  Open VSX token guard, branch restrictions and environments remain unchanged.

This is a compatible publication-workflow change, not new Find/Replace behavior.
The extension ID and the bundled client source and protocol are unchanged.

## Version and evidence

The candidate uses numeric version **0.4.6** with the pre-release marker in each
VSIX. On November 14, 2026, the highest version visible in both registries was
pre-release 0.4.5; stable 0.4.3 remained the previous stable baseline. Before
merging, repeat the registry and protected-environment checks. A later stable
release needs a different, higher version under the [versioning policy](../versioning.md).

Local tests of the overlap and safety behavior use fakes; see the
[validation record](../testing/publication-overlap.md). On November 14 the
0.4.6 candidate passed `npm run check`, 1,004 tests and strict validation of 40
OpenSpec items. A temporary source copy with a clean `npm ci --ignore-scripts`
built the universal package and all seven pre-release packages with verified
targets and markers. The local build used a fixed test epoch, not the eventual
release commit timestamp; its digests are not evidence of published bytes.

Existing 0.4.5 gallery
publication does not prove that this candidate has been published. The actual
speed of a future release is unknown: waiting may include CLI shutdown, network
and gallery processing. The release is non-atomic and may be partially visible
on failure. Client package selection, Windows/macOS native execution and mixed
Remote acceptance require separate evidence.
