# JB Search v0.2.3

This metadata-only release improves Marketplace discoverability with additional
JetBrains, IntelliJ, GoLand, Find/Replace, regex, and search preview keywords.
The extension description is now **JetBrains-style Find & Replace for VS Code.**

The display name remains **JB Search — JetBrains-style Find & Replace**, and
the extension ID remains `idfedorov09.jbsearch`. Search and replace functionality
and the bundled client component are unchanged.

## Install

Install [JB Search from the Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=idfedorov09.jbsearch),
or search for **JB Search** in the VS Code Extensions view. Existing installations
can update through Extensions.

Alternatively, download `jbsearch-0.2.3.vsix` from this release and use
**Extensions → … → Install from VSIX…**. `SHA256SUMS.txt` provides its checksum.

Desktop VS Code **1.143.1+** and a filesystem workspace are required. For known
limitations and platform evidence, see the [README](https://github.com/idfedorov09/jbsearch/blob/v0.2.3/README.md)
and [platform acceptance](https://github.com/idfedorov09/jbsearch/blob/v0.2.3/docs/testing/platform-acceptance.md).
