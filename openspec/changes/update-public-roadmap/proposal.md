# Proposal

## Why

The README roadmap is currently a release checklist. The user requested a
public view of the project's development directions without speculative
feature promises.

## What Changes

- Replace the README roadmap with the five user-provided development areas:
  search scopes, search history, navigation, platform support, and UX.
- Link to the release checklist for verification details and to GitHub Issues
  for feedback and reactions while repository Discussions is disabled.
- Keep individual features, dates, and implementation authorization out of
  this documentation update.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. The change updates public documentation without changing product behavior;
it opts out of spec deltas with `skip_specs: true`.

## Impact

The README and this OpenSpec change are affected. The user authorized a commit
and push to `dev`. No repository settings or product code need to change.
