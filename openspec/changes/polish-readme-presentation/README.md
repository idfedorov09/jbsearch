## Результат — 2026-11-04

- Шапка с PNG-иконкой, слоганом, CI/VS Code/MIT/preview badges
  и кнопками Install/GitHub/Report a bug/Donate via Tribute.
- CI показывает workflow dev; preview version автоматически читается из package.json
  удалённой dev. До push нового номера badge показывает предыдущий номер этой ветки.
- В шапке и Support development голубые Donate via Tribute badges с Telegram logo
  ведут точно на уточнённый пользователем `https://t.me/tribute/app?startapp=dTvL`.
  Прежний текст о неподключённом макете убран.
- PNG-иконка 256×256 получила скругление 32 px с прозрачными сглаженными углами.
  Внутренние пиксели и предоставленный SVG сохранены; скруглённый PNG используется
  одновременно README и manifest основного расширения.
- Сохранены английский, порядок 11 разделов и четыре будущих GIF.
