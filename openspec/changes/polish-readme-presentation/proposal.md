# Proposal

## Why

Пользователь попросил визуальное оформление README по примеру с бейджами
и красивую кнопку доната через Tribute, затем выбрал готовый README в репозитории.

## What Changes

- Оформить шапку существующей иконкой, названием, слоганом и компактными бейджами.
- Добавить кнопки Install, GitHub, Report a bug и поддержки, сохранить английский
  язык, порядок разделов и четыре места для будущих GIF.
- Подключить кнопки Donate via Tribute к персональной ссылке, предоставленной
  пользователем: `https://web.tribute.tg/d/TvL`. Не подставлять общий бот или чужого получателя.
- Проверить реальные badge URLs, локальные ссылки и обработку README упаковщиком.
- По дополнительному запросу пользователя скруглить углы PNG-иконки: радиус 32 px
  при размере 256×256, прозрачные сглаженные края, без изменения рисунка внутри.

Scope: README, media/icon.png и этот change. Исходный SVG сохраняется без изменений.
Параллельные изменения Explorer, runtime, зависимости,
финансовые операции, публикация и Git-доставка не входят в этот запрос.

## Capabilities

### New Capabilities

Нет новых возможностей расширения.

### Modified Capabilities

Нет изменений контракта runtime; `skip_specs: true`.

## Impact

README.md, PNG-иконка расширения и запись OpenSpec. Английский README и существующая
структура сохраняются. Один PNG используется и в шапке, и в manifest расширения.
