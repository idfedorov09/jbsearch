# Design

## Context

См. proposal.md. README сейчас смешивает описание продукта, подробный manual
и историю разработки. Проверенные ограничения уже описаны в docs/testing и
docs/implementation-limits.md; состояние выпуска — в docs/release-readiness.md.
Языковая настройка OpenSpec сейчас сформулирована слишком широко: All artifacts.

## Goals / Non-Goals

Сохранить заданный порядок разделов и дать короткий вход в установку и ежедневную
работу. Язык внутренней документации и runtime не меняется. Нового ADR не нужно:
архитектурных решений нет, основания реализации сохраняются в существующих ADR.

## Decisions

1. Корневой README целиком английский; AGENTS.md и CONTRIBUTING.md закрепляют
   это правило, а OpenSpec context уточняет, что русский относится к его artifacts.
2. Hero и три demo отмечаются HTML-комментариями. Это места для будущих GIF,
   без битых изображений и без генерации новых media.
3. Install ведёт к локальному разделу Installation: подтверждена упаковка VSIX,
   но публичная карточка Marketplace не подтверждена. GitHub/bug links берутся
   из package.json. Для Support development используется нематериальная поддержка,
   поскольку пользователь не предоставил платёжную ссылку.
4. Возможности Remote отделены от незавершённой приёмки физического соединения,
   Linux-проверки не представляются доказательством macOS/Windows. Privacy
   описывает отсутствие внешнего поискового сервиса и границу клиентского helper,
   не обещая отсутствие обычного трафика VS Code/Remote.
5. Ссылки на иконку из параллельного изменения сохраняются в новом README.

## Risks / Trade-offs

- Сжатие manual → сохранить установку из исходников/VSIX, shortcuts, INVALID,
  Rerun, named scopes и ссылки на технические ограничения.
- Неизвестные адреса Marketplace/донатов и будущие GIF → оставить честные
  инструкции и placeholders; сообщить пользователю, какие материалы ещё нужны.
- Параллельная работа с иконкой → править только README, языковые правила
  и отдельный change; фиксировать эти файлы отдельным разрешённым коммитом
  в `dev`, сохраняя изменения иконки и артефакты сборки.
